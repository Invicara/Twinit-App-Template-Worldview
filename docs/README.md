# World View documentation

The docs are two sections. The base template is a complete globe. Feature extensions are optional templates you can layer on afterward, and each extension has its own developer guide and user guide.

| Section | Who it is for | Start here |
|---|---|---|
| **Base template** | Developers deploying World View and the web client | [Developer Guide](base-template/developer%20guide/README.md) |
| **Base template** | Operators using the globe, sites, aircraft, and space | [User Guide](base-template/user%20guide/README.md) |
| **Template Feature Extensions** | Optional packages, including sample-airports, and the next package you add | [Catalog](feature-extensions/README.md) |
| Release history | Both sections | [Release Notes](release-notes.md) |
