# User Guide: World View

World View is a fullscreen globe. Sign in, fly the Earth, save a few locations, and turn the intel layers on when you want them.

There is no separate manager app. The project you pick in the HUD is the workspace your sites, aircraft, and space catalog come from.

## The globe

This is World View as it comes from the base template. SITES starts empty until you save a location. There is no airport list and no gate operations, and that is a complete install.

[Learn how to use World View](./world-view/README.md)

Optional features, such as airports, are documented separately under [Template Feature Extensions](../../feature-extensions/README.md). If your project does not have one of those installs, the globe will not show those controls.

If you are the person deploying the application, start with the [Developer Guide](../developer%20guide/README.md).
