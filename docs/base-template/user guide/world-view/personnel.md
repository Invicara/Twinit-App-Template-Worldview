# Personnel

The person icon at the top right opens **ACCESS CONTROL / PERSONNEL**. The dialog names the group (**World View Users**) and the current project.

## Add someone who already has a Twinit account

1. Type their email.
2. Click **ADD**.

They appear under **GROUP MEMBERS**. If the email is not a Twinit user yet, the dialog reports that no platform user has that email. An administrator has to invite them through Twinit first. This screen's ADD button does not send that invite.

If they are already in the group, the dialog says so.

## Remove someone

Click **REMOVE** on their row. Your own row says **YOU** and cannot be removed from this screen.

## Pending invites

**PENDING INVITES** lists invites already issued for this group. **DELETE** cancels one. This screen does not have a separate button to create an invite.

**CLOSE** leaves the dialog. Changes are already saved when ADD, REMOVE, or DELETE succeeds.
