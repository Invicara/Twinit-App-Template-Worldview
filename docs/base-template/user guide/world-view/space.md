# Space

The **SPACE** panel is under AIRCRAFT. The checkbox is cyan and starts off.

1. Turn the checkbox on.
2. Expand the panel.

You should see stations and visiting vehicles (for example the ISS and Tiangong) with altitude and speed. Select a row or a marker to center the camera and follow that object. A trail shows recent motion.

The list is not downloaded from the public catalog on every click. The project keeps a cached snapshot and refreshes it on a schedule, about every two hours. The globe moves the objects between those refreshes. If the panel stays empty, the project has not stored a snapshot yet. Leave the layer off and try again later, or ask the person who deployed the project to check the space-catalog job.

Turn the checkbox off to stop following and to hide the markers.
