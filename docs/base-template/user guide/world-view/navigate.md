# Fly the globe

The bottom-left **?** control opens **PLATFORM CONTROLS**. You can close it; the choice is remembered in this browser.

| Control | Action |
|---|---|
| Left-drag | Rotate |
| Right-drag | Pan |
| Scroll | Zoom |
| Ctrl + left-drag | Tilt |
| Right-click | Mark a site (see [Sites](./sites.md)) |
| Compass | Face north, east, south, or west |

## Coordinates

LAT, LON, ALT, and HDG follow the camera. Edit them and press Enter to aim the camera at that point. `INVALID COORDINATES` means the numbers could not be read. ALT is meters above the ground.

**RESET VIEW** returns to the home camera: a top-down view of the continental United States from high orbit.

## Search

**SEARCH** is available when the status line says `3D TILES ARMED`.

1. Click SEARCH.
2. Type a city or address.
3. Submit the field.

`QUERYING…` means the lookup is running. `NO FIX` means nothing matched. `QUERY FAILED` means the lookup did not complete. When several places match, **FIX CANDIDATES** lists them. Choose one to fly there, or HIDE to dismiss the list.

## Status line

Bottom right:

* `3D TILES ARMED` — close-up photorealistic tiles will appear as you descend below about 50 km.
* `3D TILES OFFLINE — AWAITING ION TOKEN` — the required Cesium ion token is missing. Tiles and search stay off until an administrator sets it and restarts the app.
