# Sites

The **SITES** panel is on the right. The checkbox turns site markers on and off. It starts on. The number is how many sites this project has. Select the header to collapse or expand the list.

Each row shows the name and the latitude and longitude. Select a row to fly there. The camera uses the altitude, heading, and pitch stored with that site. A new project has no rows until you save one.

## Save a location

1. Fly to the view you want, including altitude and direction.
2. Right-click the globe.
3. In **SAVE LOCATION**, edit **DESIGNATION**.
4. **SAVE SITE**.

The default name is the coordinates. Use a name you will recognize in the list.

## Edit or delete

1. Expand SITES.
2. Click **EDIT** on the row.
3. Change the designation, or click **UPDATE FROM CURRENT VIEW** to store the camera you have now.
4. **SAVE CHANGES**, or **DELETE** to remove the site.

If SITES already lists airports such as `DTW — Detroit Metropolitan`, this project has the optional airport install. Those rows are described in [Airports](../../../feature-extensions/sample-airports/user%20guide/airports.md).
