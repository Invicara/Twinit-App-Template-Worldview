# Sign in and choose a project

1. Open the address your administrator gave you. For a local install that is `http://localhost:8088/`.
2. Sign in with your Twinit account when the gate asks you to authenticate.
3. After the globe appears, use **PROJECT** at the top right. Pick the World View workspace you were invited to.

The project you select is the one whose sites and gate list you see. Switching project reloads those lists. It does not move your Twinit account.

If sign-in returns you to the gate or shows an error about the redirect, the address in the browser is not one the application allows. Use the exact address you were given, including `http` and the port.

**SIGN OUT** is next to the project control.

The person icon opens [Personnel](./personnel.md). The information icon opens a short architecture note. You do not need it to operate the globe.
