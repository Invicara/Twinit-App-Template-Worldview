# User Guide: sample-airports

These pages are for a project that has the sample-airports extension. SITES lists 30 large US airports, and DTW opens gate operations for the McNamara terminal.

If SITES is empty, this extension is not installed. Use the [World View user guide](../../../base-template/user%20guide/world-view/README.md) and save your own sites.

* [Airports](./airports.md) — 30 large US airports in SITES
* [Gate operations](./gate-operations.md) — McNamara terminal at DTW

If you are deploying the package, start with the [Developer Guide](../developer%20guide/README.md).
