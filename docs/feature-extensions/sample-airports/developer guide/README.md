# Developer Guide: sample-airports

sample-airports is a feature extension. Deploy the [World View base](../../../base-template/developer%20guide/deploy/d2-deploy-world-view.md) first, on the project you want. Then apply this package to that same project when you want 30 US large-hub airports and DTW McNamara gate operations. A project that never gets this package is a finished globe.

1. [Apply sample-airports](./d3-sample-airports.md)
2. [How the package works](./sample-airports.md)
3. [Test airport features](./d6-test-airports.md)

Operators of a project that has this layer: [User Guide](../user%20guide/README.md).

The checklist for the next extension is [Add another feature extension](../../adding-an-extension.md). Copy this package's shape into a new folder under feature-extensions.
